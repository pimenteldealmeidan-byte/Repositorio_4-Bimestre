# Portfólio de Natan Pimentel de Almeida

Portfólio pessoal do quarto bimestre do curso técnico em Desenvolvimento de Sistemas. Para visualizar no computador, abra `index.html` em um navegador. O site usa caminhos relativos e funciona sem instalar dependências.

## Estrutura

- `index.html` contém a apresentação, o índice de matérias, o Cointrive e os contatos.
- `materias/` contém uma página HTML editável para cada disciplina. As semanas ficam em blocos de HTML `details`.
- `materiais/` reúne os arquivos das atividades por disciplina e semana. O mapa de impacto está nos complementos do Projeto Multidisciplinar.
- `assets/` contém a folha de estilos, a foto de perfil, as ilustrações e as telas do Cointrive.

## Publicação pelo GitHub Pages

1. Extraia o ZIP e abra a pasta `portfolio-natan`.
2. Crie um repositório no GitHub para o portfólio. Envie o **conteúdo da pasta** para a branch `main`, deixando `index.html` na raiz, ao lado deste README.
3. No repositório, abra **Settings → Pages**. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha **main** e **/(root)**. Salve e acompanhe o andamento em **Actions**. Após a publicação, o endereço aparece em **Settings → Pages**.
5. Para atualizar o site, faça um novo commit na mesma branch.

Documentação: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
